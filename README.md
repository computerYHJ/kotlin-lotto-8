## 구현할 기능 목록

### 1. 입력 기능

- 구입할 가격 입력받기
- 당첨번호 입력받기
- 보너스 번호 입력받기

### 2. 입력 검증 기능

- 가격과 당첨번호, 보너스 번호가 입력되지 않았을 때 검증
- 가격과 당첨번호, 보너스 번호가 숫자가 아니면 검증
- 가격과 당첨번호, 보너스 번호가 공백일 때 검증
- 당첨번호의 갯수가 6개가 아닐 때 검증
- 가격이 1000원 미만일 때 검증
- 가격이 1000원 단위로 떨어지지 않을 때 검증
- 당첨번호와 보너스번호의 숫자가 로또 범위를 벗어날 때 검증
- 당첨번호와 보너스번호가 중복일 때 검증

### 3. 예외 감지 시 다시 실행 기능

- 입력받은 가격, 당첨번호, 보너스 번호가 예외를 발생한다면, 다시 실행하는 기능

### 4. 로또 종이 생성 기능

- 입력받은 가격을 통해 몇개의 로또종이를 생성할지 결정
- 1에서 45의 랜덤숫자를 정렬해서 list에 저장
- 모든 로또종이를 하나의 array에 저장
- array와 로또종이의 갯수를 반환

### 5. 당첨여부 계산 기능

- 크기가 5인 당첨 배열 생성. index 0 ~ 4 는 5등부터 1등임.
- 각각의 로또종이와 당첨번호를 비교 후 맞는갯수 반환
- 각각의 로또종이와 보너스 번호를 비교
- 1등과 2등은 맞는 갯수에 + 1 추가
- Array의 index는 맞은 갯수 - 3 으로 결정
- 당첨 배열 반환

### 6. 결과 출력 기능
- enum 클래스와 당첨 배열을 활용해 5등부터 결과 출력
- enum 클래스와 당첨 배열을 활용해 총 당첨금액 계산
- 총 당첨금액과 구입한 금액으로 수익률 계산
- 수익률 출력
